# React User Status App

A beginner-friendly React project that displays user cards and lets users change their online/offline status.

## Features
- Display user name and profile
- Toggle online/offline status
- Change button color based on status
- Interactive user cards

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Learned
- Components and Props
- `useState` Hook
- Event Handling (`onClick`)
- Conditional Rendering
- Dynamic Styling

## How to Run the Project

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
